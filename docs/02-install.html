Install & launch

#Install

#Windows

Download SLATE-Teams-Setup-<version>.exe, run it, and launch from the desktop icon. It installs into AppData\Local\Programs\SLATE Teams for the current user and needs no administrator rights.

The first launch opens a local window — that's the six tabs.

#macOS

Releases ship SLATE Teams.app and SLATE-Teams-Setup-<version>.dmg. From source, package it with build_macos.sh in the repository, or just run python desktop.py (see "From source" below). The installed app keeps its data in ~/Library/Application Support/SLATE Teams, not inside the bundle.

Blocked the first time you open it

An unsigned build gets stopped by Gatekeeper once. Choose "Open Anyway" under System Settings → Privacy & Security; you only do this once.

#From source

text
git clone <repo url>
cd SLATE_Teams
pip install -r requirements.txt
python desktop.py

desktop.py starts the backend and opens the window itself. If you only want the API for another browser, run python backend/main.py and open http://127.0.0.1:<port>/.

#Configure your first model

Settings → model config (the "管理模型密钥" button in the header jumps straight there): fill in one provider's API key, pick a default model, and you're running. The key stays local — one copy in data/desktop_state.json, one in browser state — and never appears in an outbound request, but it does travel with your backup. See the next box.

Your keys are inside the backup

The export packs in the whole local state, including model API keys in plaintext. A backup file is therefore a ring of keys: don't upload it to a drive, don't paste it into an issue, don't send it to anyone. To share a problem, send a screenshot and the log — nothing else.

#Coexisting with SLATE

The two products can sit on one machine without overwriting each other:

App portData
SLATEits own defaultdata/ inside its own install
SLATE Teams8130 preferred, moves on if takendata/ inside its own install

Installer identity, Start Menu entries and update feeds are all separate, so installing Teams can't hijack SLATE's auto-updates.

#If it won't start

  1. Port taken: desktop_backend.log in the data directory prints the port it actually got.
  2. Missing dependencies: most common when running from source; the error names the package.
