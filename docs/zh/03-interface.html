界面与页签

界面是一张顶栏加一块工作区。顶栏中间排着六个页签，右边四颗按钮：密钥、遥控、明暗、设置。

#六个页签

页签它装什么细写在哪
对话常规的一对一会话：边栏、消息流、顶部用量条、输入区工具行对话与审批
团队议事厅：在场席位、议事流、等你拍板团队
办公室AI 员工花名册、虚拟办公室、交办输入区，右侧五个页签：动态 / 等你拍板 / 值班表 / 岗位 / 站会与绩效办公室
黑板卡片式逻辑链与画笔层，五种显示视图：Git / 流程 / 看板 / 纲要 / 工作流黑板
扩展模型可用能力的总开关，七栏：技能 SKILL.md、工具、模式、新功能、MCP 服务、专家包、Actions扩展
设置模型与密钥、上下文与项目、审批模式、主题、通知、备份与存储，一块块往下排设置
对话页的左栏不是第七个页签

「项目 / 任务 / 总结」是对话页内部的一列边栏，切它们不会离开对话。 右边那一竖栏叠着任务清单、后台任务与磨墨面板，同样各管各的开合。

#团队页的三栏

三栏是一张会议桌的形状，各回答一件事：

  • 左栏 · 在场 —— 谁在这桌上（AI 席位与真人席位），下面还有「团队预设」和「团队历史」。 历史名单同放左栏，因为两者读的是同一件事：这一场是怎么凑起来的。
  • 中栏 · 议事流 —— 议题输入、最大辩论轮数、这一场的用量条，下面是「团队讨论 / 工作流」两个视图。
  • 右栏 · 待你签字 —— 只有主持人能做的动作：「决策需我拍板」开关，以及等你处理的条目。

#主题

内置两套：浅色与深色。顶栏「明暗」按钮切换，快捷键 Ctrl+D（macOS 上是 ⌘D）。

再往下是自定义主题（设置 → 自定义主题）：只填四个源色——页面底色、面板底色、正文颜色、强调颜色， 其余三十几个色值由它们按亮度与对比度算出来，保证正文与三个次要层级都读得清。 同一页还能调板块透明度、导入字体文件、换背景图（或取 Wallpaper Engine 的当前壁纸）。

基础预设是十档

预设行给的是十档整套源色：簿纸、墨夜、雾蓝、深海、松墨、苔绿、陶土、暮紫、石墨、铅字。 点一档就把整套色填进色板，之后仍可逐格改——改过之后它就不再属于任何预设。

开启自定义主题期间明暗切换被锁住：顶栏按钮与 Ctrl+D 都不生效，点它会说明原因。 关掉自定义主题，整段注入的样式一起摘掉，一个像素都不留。

#界面语言

应用内没有语言开关。语言在安装时选定，安装程序把它写进 data/language.txt（zh 或 en），运行时只读。

要换语言：改 data/language.txt，或者用环境变量 SLATE_LANG 启动（优先级更高），然后重启。

翻译只作用于界面文字，连按钮的提示与输入框的占位符都算；模型生成的内容、你的输入、代码块不翻。

#提示词工厂

它不再占一个页签。入口在设置 → 上下文与项目里那颗「打开工作台」。

工厂把宪法摘要、上下文片段、任务描述、约束与交付要求整合成一份可交付 Prompt。 收起只是加一层隐藏：再打开时已写的内容、勾过的文件、生成结果都还在。
