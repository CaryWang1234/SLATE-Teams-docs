对话与审批

#对话页能做什么

一列边栏、一条会话区、一行输入区。

  • 边栏三个页签：项目（目录与文件树）、任务（历史会话，可搜索、批量管理、归档）、总结。
  • 会话区上方：手动压缩上下文、记忆与画像、专家包管理、提示词素材、任务清单、后台任务，再下面是那条用量栏。
  • 输入区左下：「＋」模式与功能浮层——磨墨模式、头脑风暴、目标模式、定时任务，以及 @ 提及技能 / 工具 / MCP / 文件； 旁边依次是回复模式、审批模式、附件、专家包、模型、推理强度。
  • 输入区右下：优化提示词、语音输入、发送。Enter 发送，Shift+Enter 换行。

回复模式内置四档：智能、对话、经济、狂暴。差别在带不带工具目录、给几轮、追加哪段提示词； 自定义模式在 扩展 页管。

#审批模式：四档

输入框左下那颗胶囊就是审批模式，四档，随时可改，改的只是这一场：

id标签放行什么拦住什么
ask手动审批读写本地文件等不走审批的工具执行命令、访问网络，每一笔都先弹窗问你
auto自动审批命令与联网里没命中高危规则的只命中高危规则那一类问你
full完全访问命令与联网一律不问缺条件时仍会向你确认一次；灾难级命令照旧硬拦
night夜间模式命令、联网、提问全部不问只拦灾难级命令

ask 是新对话的默认档。设置 → 审批模式 改的是新对话的默认档；某一场挑过之后就不再跟随它。

走这道门的只有五件事

terminal 执行命令、bg_task 起后台任务（查状态 / 看日志 / 停止不改环境，不算）、 web_search、web_fetch、browser_automation。读写本地文件不走这道门。

#夜间模式到底是什么

它是全托管那一档：与完全访问同一条放行口径，外加把「缺条件时向你提一道选择题」也关掉。 遇到选择题不弹窗，直接让你从选项里自行拍板继续，并把选定的方案与理由写进回复。

它不是第四种放行规则，也不新开一套口子——差别只在「有没有任何东西在等人」。 配合「夜间模式运行任务时保持系统唤醒」（设置 → 审批模式，默认开着）过夜跑。

灾难级命令任何档都拦

rm -rf /、rm -rf ~、format c:、format d:、mkfs、dd if= 这几条前缀由后端无条件拒绝， 批准了也不放行。完全访问标红（没有安全网），夜间模式标夜紫（这一晚交给它）。

#高危清单在哪

前后端各一份同一条清单，两处都要改才对齐：

  • 前端：frontend/js/services/riskguard.js 的 HIGH_RISK_PATTERNS，另加一条「下载后直接管给 shell」。
  • 后端：backend/skills/terminal.py 的 HIGH_RISK_PATTERNS（多一条 PowerShell 的 ri 别名）与 BLOCKED_PREFIXES。

规则是写死的，覆盖删除文件与目录、磁盘写入与分区、关机重启、提权、强杀进程、注册表、服务与账户、 文件权限、Git 强推 / 硬重置 / 清理 / 删分支、数据库删表删库、卸载全局依赖。命令会先按 &&、||、;、| 拆段逐段检测，所以链式命令里藏一条也逃不掉。

#审批框长什么样

标题分三种：高危命令审批 / 命令执行审批 / 联网访问审批。框里写清触发规则或当前档位， 列出那条命令或那个访问目标；命令类还会用当前模型解释它的目的（可在设置 → AI 辅助功能关掉）。 按钮是「批准执行」或「允许访问」。

并行时可能一次挤出好几张：它们排队，后来的不会在你没看见之前被自动拒掉。 拒绝的理由会原样回给模型，并明确要求别再重试同一笔调用。

#工具调用在界面上怎么呈现

每次调用是一张卡片：工具图标 + 名称 + 一句摘要 + 状态药丸。状态写的是 已执行 / 已应用 / 已创建 / 已追加 / diff 预览 / 文件预览 / 追加预览 / 失败 / 未执行。

卡片默认收起，只有失败的那张自动展开；点开看参数与输出。文件改动的参数只列文件路径与编辑条数， 不铺整份 diff。工具生成的图片、视频、文档会在卡片里直接给预览。

一次跑了好几笔会归成一组，标题写「调用 N 项」，后面列前三个工具名。
