扩展是顶栏第五个页签，副标题一句话：**模型可用的能力在此页决定**。
左栏是一条分栏轨，七栏各带一个计数；轨上的数字与栏内标题上的数字同源，一处刷新两处一起变。

| 栏 | 管什么 | 你能做什么 |
| --- | --- | --- |
| 技能 | 一份写给模型的做事说明（SKILL.md） | 新建、从本地路径导入、从 GitHub 仓库导入、扫描标准目录发现已装插件、删除、点开试跑 |
| 工具 | 后端常驻能力，模型经 skill_run 调用 | 只读清单，点开可执行；**内置工具不可删除** |
| 模式 | 回复模式 | 内置四档只读，自定义可增改删 |
| 新功能 | SLATE 自己生成的工具，放在 `data/evolved/` | 启用 / 停用、回滚到历史版本、撤销（删前先进历史） |
| MCP | 外部 MCP Server 带来的远程工具 | 添加、连接 / 断开、删除、按项目单独启停 |
| 专家包 | 角色设定 + 规则 + 知识库 + 技能打成一份包 | 新建、导入 zip、导出、增删包内文件 |
| Actions | 流程说明书 | 新建、编辑、删除、回滚 |

## 技能与工具不是一回事

**技能**是一份 SKILL.md：你用自然语言写清"遇到这类活怎么做"，导入后模型按任务自己取用。
随产品带的示例技能有 **6 份**（代码审查、提交信息、设计、调研、周报、Windows 排障）。

**工具**是后端常驻的代码能力，这一栏列的是内置注册表里的 **35 项**——从读文件、改文件、跑终端、
后台任务，到生成 PPT/Word/Excel/PDF、浏览器与桌面自动化、联网搜索与网页获取。
它们只读、不可删除；你在界面上能关掉的，是[设置](./14-settings.md)里那些会自行调模型的功能：
**关掉的功能连模型的工具目录都不会出现**。

另有一批对话内工具（读写黑板、工位递话、建回复模式、收口目标模式等）不在这张清单里单列，
由回复模式的工具白名单决定开不开。

:::tip 想加新工具而不想写代码
用「工具工厂」（内置工具 mcp_factory）生成一个，产物落在 `data/evolved/`，
出现在**新功能**这一栏，随时可停用、回滚、撤销。每次覆盖、撤销、回滚都先存入历史版本，最多留 5 版。
:::

## 回复模式

回复模式决定**这一场对话用哪套提示词、开放哪些工具、跑几轮、思考强度多高、用哪只模型**。
内置四档只读：**智能**（带全套工具）、**对话**（不给工具，一轮就停）、**经济**（只给只读工具、
低强度、12 轮）、**狂暴**（全套工具、高强度、40 轮，中途不停下来等确认）。

自定义模式是一份完整规格：id、显示名、图标、颜色、追加提示词、工具白名单（逐格勾）、
推理强度、轮数上限、指定模型（默认跟随当前主模型）。模型自己也能建模式——它调 mode_write
工具，落点与你手动建的是同一份注册表。

:::warning 两件事别混
在输入框上方改的是**这一场用哪个模式**；在扩展页「模式」栏改的是**模式本身长什么样**。
删除一个正在被使用的自定义模式不会崩，用到它的会话回落到默认模式。
:::

审批模式（手动 / 自动 / 完全访问 / 夜间）是另一套东西，管的是**命令与联网要不要问你**，
在设置页里定默认档，见[对话与审批](./05-chat-approval.md)。

## 专家包

一份专家包 = 人格设定 + 行为规则 + 知识库文件 + 技能文件，打成一个可切换的整体。
随产品带的示例包有 **3 份**。用法两条：对话时在下方的专家包选择器里选一份注入这一场；
在[团队](./06-team.md)里则挂到某个 AI 席位上。

## MCP 与 Actions

MCP 这一栏连的是外部 Server，连上后它的远程工具进入模型视野；与内置同名的远程工具由内置接管。
每台服务器可以全局停用，也可以只对当前项目单独启用或停用（项目掩码），摘掉掩码就回到全局配置。

Actions 是一份份**流程说明书**：把常规操作写成必需步骤，模型按流程执行。
存成 `data/actions/<id>.yml`，也可以放进项目自己的 `.slate/actions/`——项目里同名的那份优先。
每次覆盖都留底，最多 5 版，可回滚；解析不了的旧版本不允许盖回去。
在[黑板的工作流视图](./10-board.md)里，一份 Action 就是一张可就地运行的卡片。
