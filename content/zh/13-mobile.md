遥控是**同一套后端的另一张脸**：手机浏览器连的是你机器上那个后端，跑的还是同一台引擎。
它不新增服务，也不新增第二种执行方式。

## 手机上有什么

五个页签：**对话**、**会话**、**记忆**、**待办**、**设置**。

- 对话里流式续写、思考折叠、工具卡片都在；工具真能改文件（写文件、改文件、追加都走同一批接口）。
- 审批换成了底部弹层：高危命令与文件变更照样要你点头，改动先给一份 diff 预览再决定接受还是拒绝。
- 设置里四件事：遥控地址与二维码、选模型、填密钥、切主题。
- 这一趟结束后，后台任务的完成事件也照样被读回来。

## 手机上没有什么

**团队、办公室、黑板、扩展**这四个页签只在桌面上。所以：

- 手机上开不了议事厅，也看不见交付队列；与会者拿票据进的是另一页（只有那一场讨论），
  不是工作台——把他领进整套工作台只会让他看到一片被拒的请求。
- 手机页面**不领办公室的活**。后端只排队不执行，而当班的是桌面上那个开着的页面；
  只有手机在线、桌面全关着，员工的活会安静地留在队列里。

:::warning 手机是遥控器，不是第二台机器
文件、Git、终端、账本全在你那台主机上。主机睡了，手机那边没人替你干活。
:::

## 怎么进手机界面

带授权码的地址在手机浏览器里打开后，界面按移动 UA 自动分流到为触屏重排的那一页，
地址后面的授权码原样保留。不想用移动版就在地址后面加 `slate_mobile=0` 回到桌面版。

## 遥控开关在哪拨

**设置 → 局域网遥控 → 启用局域网遥控**，就这一处。

- 偏好记在本机 `data/desktop_state.json`；文件不在、读坏了、没这个键，一律按"开"处理。
- 关掉是**真的把局域网那个监听端口释放掉**，不是把地址藏起来。
- 这个开关**只能在主机上拨**。从遥控端口拨过来会被拒——你正靠这条连接做事，关掉等于把自己
  关在门外；而"打开"方向在服务停掉之后根本不可达。

## 地址怎么拿

主机那一块设置里列出带授权码的地址，可以直接复制，也可以扫码。地址由本机局域网 IP 和
副服务**实际抢到的端口**拼出来：首选端口被占就向上让，所以别把端口写死在别处。

:::note 重启之后要重新复制
主授权码是每次进程起来时新生成的一份，重启就换。手机上的旧地址会停在"需要授权"那一页，
回到主机的设置里再复制一次即可。
:::

## 无界面模式

```
python desktop.py --remote
```

给没有桌面环境的机器用的（服务器、树莓派、容器）：不开窗口、不起托盘，只起后端与局域网遥控，
然后把本机地址和带授权码的遥控地址打到终端，按 Ctrl+C 收尾。

- 它强制**本次进程**开启遥控，不写进偏好文件；也不复用别人已经起好的后端——远程模式下
  手上没有界面可以补救，必须保证这次一定有遥控。
- 后端起不来时把原因写在终端，细节留给 `desktop_backend.log`；没有窗口可以承载失败页。

## 为什么只换脸

工具循环、消息组装、审批判定、渲染逻辑都在桌面上那份服务模块里，手机这一侧只注入自己的
视图与输入。两张脸共用一颗引擎，是为了不出现"手机上看着能做、其实做的是另一套"。
代价也很实在：议事与办公室的交互搬不进触屏，就干脆不搬，页签在手机上直接不存在。
