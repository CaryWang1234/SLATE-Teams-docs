设置是顶栏第六个页签。左栏一份锚点导航、上方一个搜索框，右栏是分组区块；
**导航条目由页面现读区块生成**，所以组数随版本变，但顺序与主区始终一致。当前共 **21 组**：

模型配置 · API 测试 · 用量统计 · 上下文与项目 · 自动推进 · AI 辅助功能 · 通知 · 后台任务 ·
多任务与项目 · 通用 UI（实验性）· 自定义主题 · 联网搜索 · 图片生成 · 视频生成 · 审批模式 ·
数据备份与恢复 · 会话归档 · 存储空间 · 局域网遥控 · 打字小游戏 · 关于。

改完点右上角**保存**统一落盘。界面语言**不在这里**：它在安装时选定（写入 `data/language.txt`），
应用内不切换，优先级是环境变量 `SLATE_LANG` > 该文件 > 默认中文。

## 模型与上下文

**模型配置**里两件事：自定义模型（名称/ID、请求模式 OpenAI 兼容 / Anthropic / curl 直连、
Base URL、API Key、Context Window）和内置模型密钥。下面还有一条可选的 Responses API 开关。
**API 测试**用一条最短请求打一次真实链路——它走的就是对话那条路，不是另造一条。

**上下文与项目**这组决定模型一次能看到多少：

- 上下文 Token 上限：内置模型与已填窗口的模型走「自动」，各取标称窗口的八成；
  这一档只给完全没有窗口信息的模型兜底。要单独调某只模型，用模型配置里那一行的「最大上下文」——
  滑杆粗选、旁边的数字框可填精确值、本地与自定义端点还能**探测窗口**。压缩阈值与上下文条按同一个数算。
- 单次输出上限（1024–65536）；默认勾上「输出文件时把长度上限提到 65536」，避免大文件被截断。
- 默认勾上「自动确认文件创建与修改」；关掉后恢复成写文件前先预览、点接受。
- **项目宪法**：这一项目里长期有效的硬规则。同组还有提示词工厂的入口。

## 自定义主题

启用自定义主题后，配色**只填四个源色**（页面底色、面板底色、正文、强调），其余色值由它们按亮度
与对比度算出来——正文与三个次要层级都会被拉到能读的清。预设色板有 **10 档**：
簿纸、墨夜、雾蓝、深海、松墨、苔绿、陶土、暮紫、石墨、铅字。点一个预设就把整套源色填进色板，
之后仍可逐格改；**改过之后这一份就不再属于任何预设**。

:::warning 开启期间明暗切换被锁
自定义主题开启时，顶栏的明暗按钮与 Ctrl+D 不生效，点它会说明原因。关闭自定义主题，整套回到内置主题。
:::

- **字体**：系统已装的字体族按名字直接用；「导入字体」只收单个 `.woff2 / .woff / .ttf / .otf`
  （16MB 以内），文件**只落在本机 `data/theme/fonts/`**——不进对话记录、不进仓库、不进安装包，
  也不会跟着备份到另一台机器。只导入一个字重时，粗体与斜体由浏览器模拟。
- **板块透明度**（55%–100%）是面板、卡片、输入框与助手气泡那一层底色的**平面不透明度**，
  调低透出的是页面底色或背景图，**不是毛玻璃模糊**；用户自己的气泡与代码块始终实色。
- **背景图**存在本机 `data/theme/`，配一条遮罩浓度（40%–95%）：过低会让正文压在图上，过高等于没铺图。
  Wallpaper Engine 那栏只读取它自己目录里的配置与 preview 图，取来当背景图——不启动它、也不改它的设置。

## AI 辅助功能

除对话、团队讨论、提示词工厂外，所有会**自行调用模型**的功能都在这一组：共 **15 项**，
逐项开关，其中 **12 项**还能各选一只模型。剩下三项不带模型栏，因为模型另有归属：
定时与事件任务的模型**在每个任务里各自选**，图片生成与视频生成的模型与 Key 在各自区块配置。
**关掉一项，就不再为它发任何请求。**

覆盖的是：上下文压缩摘要、记忆自动蒸馏、记忆手动提取、对话洞察捕获、自动会话标题、
代码理解文档、代码审查、黑板 AI 整理、提示词优化、子代理并行、高危命令目的说明、团队工作流执行。

「自动推进」的审阅模型和「后台任务」的自动续跑在各自区块里设，这里不重复列。

## 能力为什么不在这里管

工具、技能、回复模式、专家包、MCP、Actions 全部在[扩展](./11-extensions.md)页——那里是能力清单的
**唯一一处真相**。设置页只留两类东西：能力的**供应商配置**（联网搜索引擎与渲染方式、图片/视频生成的
模型与 Key）和能力的**调用闸门**（上面那 15 项开关）。同一件事在两处各管一半，不会各说各话。

:::note 审批模式在这里，回复模式不在
这组里定的是新对话的默认**审批模式**（手动 / 自动 / 完全访问 / 夜间）；
**回复模式**是[另一回事](./11-extensions.md)，在输入框上方按场挑。
:::

## 数据与设备

**数据备份与恢复**导出单个 JSON（对话、议事与账本、员工名册与值班表、记忆、素材、设置），
恢复按 id 合并、不覆盖已有数据；细目见[项目与数据](./12-projects-data.md)。
**会话归档**放从「任务」栏归档的会话，可恢复可彻底删除。**存储空间**可压缩数据库、清缓存。
**局域网遥控**开一个本机地址给手机或平板，用法见[移动端](./13-mobile.md)。
